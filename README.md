## 一、先弄懂"香港VPS KVM"的几个底层概念

在掏钱之前，有三件事值得先想清楚，不然很容易买完才发现买错了。

**KVM到底比OpenVZ强在哪**。KVM是全硬件虚拟化，每台VPS像独立的小服务器一样有自己的内核、自己的Swap、自己的资源隔离；OpenVZ是容器虚拟化，共享宿主机内核，不能装Windows、不能改内核、容易被"邻居"影响。简单说，KVM更接近真实服务器，折腾空间大、隔离干净；OpenVZ便宜但受限多。野草云全系默认KVM，这点不用额外操心。

**线路名称不是越花哨越好**。香港到大陆的回程线路，本质上是数据从香港"走哪条路"回到国内运营商。常见有这么几种：CN2（中国电信第二代承载网，比普通163线路优）、CN2 GIA（CN2里的高优先级专线，最稳最快也最贵）、CMI（中国移动国际）、CU（中国联通国际）、NTT/Level3/Telstra等国际运营商。所谓"优质BGP""精品BGP""国际BGP"是商家自己组合出来的多线BGP方案，本质是上面这些线路的混合搭配，看的是回程怎么走、晚高峰稳不稳。

**带宽和流量是两回事**。"100M带宽"指的是端口速率上限，"600GB/月"指的是一个月能跑多少数据。小带宽+不限流量适合长期跑服务但流量不大的场景（比如个人博客、API），大带宽+限制流量适合偶尔爆发大文件下载、视频转码这类场景。买之前先估自己的业务属于哪种，别只看价格便宜就下单。
